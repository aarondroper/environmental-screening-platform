- SSURGO: retain SDA/WSS query or package responses with per-SSA `saversion`/`saverest`; preserve map-unit geometry and component relations through `mukey`/`cokey`, including null/unranked ratings. If packages are used, keep original survey-area packages and clip only in staging.
- FEMA: preserve dated effective snapshots and pending products separately; attach community, panel and effective-date metadata; represent unmapped/unavailable coverage as unknown.

No application, schema, adapter, dependency or deployment implementation is represented by these patterns.
