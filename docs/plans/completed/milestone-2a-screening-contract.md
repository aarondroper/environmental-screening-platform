# Milestone 2A — screening workflow and product contract

## Objective

Define the intended analyst workflow, per-source screening result contract, source maturity/coverage semantics, and automated acquisition/validation adapter boundaries without implementing the application or claiming final source approval.

## Outcome

Defined `docs/SCREENING_CONTRACT.md` covering project/AOI revisions, asynchronous jobs, source maturity versus AOI coverage, explicit observation/unknown states, source-specific metrics, provenance, exports, limitations, and automated ETL adapter contracts for all five selected sources. Recorded the current validation scopes and preserved PAD-US/FEMA as unresolved final Milestone 1 approvals. Updated architecture, project state, backlog, and source-feasibility frontier. No application code, schema, dependency, deployment, or source-set change was made. The contract remains design documentation; Milestone 2A does not imply implementation readiness or full source approval.
